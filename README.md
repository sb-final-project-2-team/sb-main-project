# 👗 옷장을 부탁해 (Please Take Care of My Closet)

> **당신의 OOTD, 여기서 편하게.**
> 날씨와 취향을 고려한 맞춤 코디 추천부터 패션 커뮤니티까지,
> 매일 아침의 고민을 줄여주는 **지능형 패션 플랫폼**입니다.

---

## 📌 프로젝트 소개

아침마다 반복되는 "오늘 뭐 입지?"라는 고민,
기온만 보고 외출했다가 겪는 착장 실패,
그리고 옷장 속 아이템을 제대로 활용하지 못하는 문제를 해결하기 위해
**옷장을 부탁해**는 탄생했습니다.

본 프로젝트는 **실시간 날씨 기반 의상 추천**, **가상 옷장 관리**,
그리고 **OOTD 중심의 패션 커뮤니티**를 통해
사용자에게 더 스마트한 의사결정을 제공합니다.

## 🛠 기술 스택

### Backend & Security

* **Framework**: Spring Boot, Spring Data JPA
* **Security**: Spring Security, OAuth2 (Google, Kakao)
* **Data**: PostgreSQL, Redis, Kafka, ElasticSearch

### Infrastructure & DevOps

* **Server**: AWS, Nginx (Reverse Proxy & Load Balancing)
* **CI/CD**: GitHub Actions, Docker
* **Monitoring**: Prometheus, Grafana

### Collaboration

* **Code Review**: GitHub Pull Request, CodeRabbit (AI 기반 리뷰)
* **Communication**: Daily Double Check-in (아침 / 저녁 공유)

## 🌟 주요 기능

### 1️⃣ 지능형 의상 추천

* 실시간 날씨 데이터(기온, 체감 온도, 강수 확률 등)를 연동하여
  상황에 맞는 최적의 코디를 추천합니다.
* 사용자별 **온도 민감도 설정**을 통해 개인화된 추천 결과를 제공합니다.

### 2️⃣ 가상 옷장 관리

* 사용자가 보유한 의상을 등록하고 속성(카테고리, 계절 등)을 관리합니다.
* 의상 이미지 및 구매 링크를 저장하여 **디지털 옷장**을 구성할 수 있습니다.
* 중복 구매를 방지하고 기존 의상의 활용도를 높입니다.

### 3️⃣ 패션 커뮤니티 (OOTD)

* 오늘의 착장(OOTD)을 피드 형태로 공유할 수 있습니다.
* 다른 사용자의 스타일을 탐색하고 영감을 얻을 수 있습니다.
* 팔로우 및 DM 기능을 통해 취향 기반의 소통이 가능합니다.

### 4️⃣ 관리자 및 기타 기능

* 비밀번호 초기화 및 프로필 관리
* 사용자 위치 등록 및 알림 서비스 제공
